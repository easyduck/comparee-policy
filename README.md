# Comparee — legal pages

Public privacy policy for the Comparee iOS app, hosted with GitHub Pages.

- English: https://easyduck.github.io/comparee-policy/
- ไทย: https://easyduck.github.io/comparee-policy/th.html

Use the English URL as the privacy policy URL in AdMob (Privacy & messaging) and
in App Store Connect.

## Before submitting

`index.html` and `th.html` both still contain three highlighted placeholders:
`[EFFECTIVE_DATE]`, `[DEVELOPER_NAME]`, `[CONTACT_EMAIL]`. Fill them in and the
draft notice can be deleted.
